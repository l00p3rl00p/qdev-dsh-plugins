# DSH Plugin Build Rule

Before installing any plugin we build, edit, or modify, we must **Test → Commit → Package → Verify SHA → Install**. Only an explicit user override permits an exception.

**Sole active ACC source:** `plugins/dsh-auto-code-correct` in this repository. The older standalone ACC repository is deprecated; never push ACC work there.

This repository is public. Follow the root [AGENTS.md](../../AGENTS.md): no secrets, no private-repository or machine-specific references, and the plugin must run standalone.
