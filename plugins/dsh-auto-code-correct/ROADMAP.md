# Auto Code Correct — upcoming features

The release roadmap records prospective functionality rather than engineering tasks.

## Upcoming features

- **Persistent native controls:** ACC preferences that survive reopening and restarting DSH.
- **Language readiness dashboard:** clear availability and status for Python (Ruff + ty), Rust (rustfmt + Clippy + cargo check), and TypeScript (ESLint + Prettier + tsc).
- **Visible correction outcomes:** improved in-session display of completed correction operations and remaining diagnostics.
- **Controlled correction experience:** configurable, bounded automatic correction with Git hygiene visibility.

Build order, package checks, regression fixes, and release validation are tracked in the [overall backlog](../../BACKLOG.md), not this feature roadmap.
