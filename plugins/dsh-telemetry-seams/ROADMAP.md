# Telemetry Seams — upcoming features

## Upcoming features

- **Evidence-backed delivery health:** distinguish configured telemetry interfaces from verified end-to-end signal delivery.
- **Active profile provenance:** identify the DSH profile associated with probe evidence through supported DSH interfaces.
- **Expanded downstream visibility:** inspect evidence for OTEL and supported analytical consumers while preserving read-only behavior.

The existing one-shot, opt-in probing behavior and no-transport-ownership rule remain part of the plugin's baseline. Build tasks, tests and acceptance details belong in [BACKLOG.md](../../BACKLOG.md), not this feature roadmap.
